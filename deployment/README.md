# Pacchetti di deployment

I pacchetti descrivono come usare il medesimo Core su piattaforme diverse. Non contengono varianti autonome della metodologia e non rendono equivalenti le funzioni dei diversi prodotti.

| Piattaforma | Modalità persistente documentata | Disponibilità / limiti rilevanti | Alternativa universale |
|---|---|---|---|
| ChatGPT | Istruzioni per Progetto; Custom Instructions globali | Progetti disponibili ai piani autenticati in base all'account/workspace; file per progetto: Free 5, Go/Plus 25, Edu/Pro/Business/Enterprise 40. Custom Instructions globali con campi testuali da 1.500 caratteri | Chat standard |
| Microsoft Copilot Notebooks | Istruzioni per singolo notebook e fonti collegate | Copilot Chat: fino a 50 fonti e tipi limitati; Microsoft 365 Copilot: fino a 300 fonti e riferimenti aggiuntivi. Non è un GPT personalizzato globale | Copilot Chat o altra chat standard |
| Google Gemini | Skills per account personali maggiorenni | Skills personali disponibili; Gems in transizione. Workspace previsto nel 2027; Skills non supportano ancora tutte le funzioni Gemini | Chat standard |
| Anthropic Claude | Projects con istruzioni e knowledge base | Disponibile anche Free (massimo 5 Projects); RAG avanzato a pagamento; condivisione Team/Enterprise | Chat standard |
| Altri chatbot | Dipende dal prodotto | Da verificare prodotto/account per prodotto/account | Chat standard |

Le funzioni e i limiti possono cambiare. Consulta le fonti ufficiali nei rispettivi file e registra piano, account, modello e data durante i test. La presenza di un deployment documentato non equivale a compatibilità empirica verificata.
