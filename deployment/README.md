# Pacchetti di deployment

I pacchetti descrivono come usare il medesimo Core su piattaforme diverse. Non contengono varianti autonome della metodologia.

| Piattaforma | Modalità persistente documentata | Alternativa universale |
|---|---|---|
| ChatGPT | Istruzioni progetto; istruzioni personalizzate globali | Chat standard |
| Microsoft Copilot Notebooks | Istruzioni per singolo notebook | Chat standard |
| Gemini | Skills in transizione da Gems per account personali | Chat standard |
| Claude | Istruzioni di progetto (Projects a pagamento) | Chat standard |
| Altri chatbot | Dipende dal prodotto | Chat standard |

Le funzioni e i piani cambiano. Consulta le fonti ufficiali nei rispettivi file e verifica l'interfaccia del tuo account.
