# Guida all'installazione e configurazione

## Requisiti
Un chatbot che accetti testo e una copia delle istruzioni. Non servono Git, terminale, codice, server, database o API a pagamento.

## Scaricare
Apri il repository GitHub, seleziona **Code > Download ZIP**, estrai l'archivio e apri la cartella `instructions`. In alternativa apri i singoli file su GitHub.

## Configurare
1. Apri `instructions/CORE_INSTRUCTIONS.md` e copia il contenuto completo.
2. Incollalo nelle istruzioni permanenti, se il chatbot offre questa possibilità.
3. Se non esiste un campo dedicato, apri una nuova chat e segui `instructions/UNIVERSAL.md`.
4. Invia una richiesta concreta per iniziare.

Le guide ChatGPT, Gemini e Claude sono opzionali: nomi delle funzioni e disponibilità possono cambiare. Consulta i riferimenti ufficiali.

## Aggiornare
Scarica lo ZIP della nuova versione, leggi `CHANGELOG.md`, confronta le istruzioni e integra le tue personalizzazioni prima di sostituire la copia in uso.

## Problemi comuni
- **Limite di testo:** non presumere che il contenuto sia stato acquisito. Usa modalità universale o invio in parti numerate, se la chat conserva il contesto.
- **Istruzioni non persistenti:** reinseriscile nelle nuove conversazioni.
- **Funzione assente:** usa la chat standard; nessuna funzione premium è necessaria.
