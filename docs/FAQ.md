# FAQ

## Il progetto è gratuito?

Sì. Il kit è distribuito gratuitamente.

## Devo acquistare API?

No. Non sono necessarie API a pagamento.

## Devo programmare?

No. La configurazione principale utilizza istruzioni testuali.

## Funziona con qualsiasi chatbot?

Il progetto punta alla massima compatibilità, ma le funzionalità
dipendono dalla piattaforma utilizzata.

## Posso contribuire?

Sì. Puoi proporre modifiche tramite Issue e Pull Request.
