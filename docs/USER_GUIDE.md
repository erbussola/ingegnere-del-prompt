# Guida utente

Questa guida descriverà come utilizzare Ingegnere del Prompt.

L'obiettivo è consentire a chiunque di configurare
il proprio assistente AI senza sviluppare applicazioni.

Contenuti previsti:

1. Introduzione al progetto.
2. Download dei materiali.
3. Scelta del chatbot.
4. Configurazione delle istruzioni.
5. Primo utilizzo.
6. Esempi pratici.
7. Aggiornamento delle istruzioni.
8. Risoluzione dei problemi.
