# Guida utente

## 1. Scegli cosa fare
- **Creazione:** parti da un'idea o da una richiesta semplice.
- **Ottimizzazione:** incolla un prompt esistente.
- **Progettazione:** descrivi l'assistente che vuoi configurare.

## 2. Configura
Copia tutto [CORE_INSTRUCTIONS.md](../instructions/CORE_INSTRUCTIONS.md) nel campo delle istruzioni permanenti, se disponibile. Altrimenti incollalo come primo messaggio in una nuova conversazione seguendo [UNIVERSAL.md](../instructions/UNIVERSAL.md). Le guide piattaforma sono facoltative.

## 3. Primo utilizzo
Esempio: «Crea un prompt per organizzare un corso di fotografia per principianti, con lezioni settimanali e attività pratiche». Non devi compilare RICCE: l'assistente ricava gli elementi utili e chiede chiarimenti solo se indispensabili.

## 4. Comprendi il risultato
Per attività articolate riceverai analisi, cinque suggerimenti se l'ottimizzazione è sostanziale, prompt completo copiabile e valutazione motivata. I cinque criteri sono chiarezza, completezza, specificità, coerenza e utilizzabilità. Il punteggio è qualitativo, non scientifico.

## 5. Itera
Chiedi modifiche circoscritte, ad esempio «Mantieni la struttura e rendi il tono più formale». Il prompt completo deve essere restituito a ogni revisione; le parti approvate non vanno cambiate arbitrariamente.

## 6. Template e aggiornamenti
Scegli un file in [templates](../templates/), sostituisci i campi tra parentesi quadre e rimuovi quelli non pertinenti. Per aggiornare il kit scarica la nuova versione, leggi il changelog e integra le personalizzazioni prima di sostituire le istruzioni.

Non inserire dati riservati senza aver verificato le condizioni del servizio AI.
