# Configurazione universale

Questa modalità non richiede istruzioni permanenti, progetti o assistenti personalizzati.

1. Apri una nuova conversazione.
2. Copia tutto `instructions/CORE_INSTRUCTIONS.md`.
3. Incollalo come primo messaggio.
4. Se il servizio segnala un limite, non presumere che abbia acquisito il testo completo. Puoi inviarlo in parti numerate e chiedere al modello di attendere «FINE», se la chat conserva il contesto.
5. Invia la tua richiesta.

Messaggio facoltativo: «Applica le istruzioni appena ricevute come Ingegnere del Prompt per questa conversazione. Se non hai acquisito una parte o non puoi applicarla, segnalamelo. Aiutami a creare, ottimizzare o progettare un prompt».

Le istruzioni valgono nel contesto corrente. Non è garantita la persistenza in altre chat né la disponibilità di strumenti o funzioni premium. Per le nuove conversazioni ripeti la procedura, salvo configurazione persistente della piattaforma.
