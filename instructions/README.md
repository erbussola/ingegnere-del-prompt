# Istruzioni distribuibili

- [CORE_INSTRUCTIONS.md](CORE_INSTRUCTIONS.md): bundle completo, autosufficiente e copiabile in una normale chat o in un campo istruzioni.
- [COMPACT.md](COMPACT.md): versione breve per campi con limiti stringenti.
- [UNIVERSAL.md](UNIVERSAL.md): procedura d'avvio in chat standard.
- [CHATGPT.md](CHATGPT.md) e [GEMINI.md](GEMINI.md): collegamenti alle guide aggiornate in `deployment/`.

I moduli normativi sono in `core/`. Quando cambia un modulo Core, aggiornare contestualmente i bundle e i test: un collegamento a un file del repository non sostituisce le istruzioni autonome da copiare.
