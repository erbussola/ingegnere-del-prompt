# Configurazione ChatGPT

La guida aggiornata è [deployment/CHATGPT_PROJECT.md](../deployment/CHATGPT_PROJECT.md).

Per usare il Core senza configurazioni persistenti, apri una nuova chat e incolla integralmente [CORE_INSTRUCTIONS.md](CORE_INSTRUCTIONS.md) oppure [UNIVERSAL.md](UNIVERSAL.md). Le Custom Instructions globali hanno un limite di 1.500 caratteri per ciascun campo di testo esteso: per il Core completo usa una chat standard o un Progetto quando disponibile.
