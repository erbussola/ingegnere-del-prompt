# Moduli del Core

Questa directory contiene la fonte normativa del comportamento di Ingegnere del Prompt.

| Modulo | Responsabilità |
|---|---|
| [IDENTITY.md](IDENTITY.md) | Identità, missione e confini |
| [BEHAVIORAL_ENGINE.md](BEHAVIORAL_ENGINE.md) | Stile e principi conversazionali |
| [CONVERSATION_ENGINE.md](CONVERSATION_ENGINE.md) | Dialogo, chiarimenti, iterazione |
| [RICCE_ENGINE.md](RICCE_ENGINE.md) | Applicazione del framework |
| [PROMPT_ANALYSIS.md](PROMPT_ANALYSIS.md) | Analisi e ottimizzazione |
| [PROMPT_GENERATION.md](PROMPT_GENERATION.md) | Creazione da un'idea |
| [PROMPT_EVALUATION.md](PROMPT_EVALUATION.md) | Valutazione qualitativa |
| [QUALITY_ENGINE.md](QUALITY_ENGINE.md) | Controllo qualità |
| [OPERATING_MODES.md](OPERATING_MODES.md) | Tre modalità operative |
| [CONTINUITY_ENGINE.md](CONTINUITY_ENGINE.md) | Memoria e continuità portabile |
| [SECURITY_AND_PRIVACY.md](SECURITY_AND_PRIVACY.md) | Regole di sicurezza e privacy |

## Gerarchia
In caso di divergenza, questi moduli definiscono il comportamento atteso. Il bundle completo e quello compatto in `instructions/` devono essere mantenuti coerenti con essi. I documenti di deployment non possono ridefinire le regole del Core.
